# MATLAB 图表规范

本文件的算例故事、指标、数据登记和正式导出要求适用于算例与结果分析图。机理示意图、算法流程图、理论框架图和方法原理图根据任务选择表达方式和制作工具。全部 MATLAB 图形，包括诊断图和示意图，均遵守白色背景约定。

开展相关任务前显式读取本文件，并遵守根目录 `AGENTS.md`。绘图实现保存在本目录；算例图表计划保存在 `01_IDEA/figure_plan.md`。

## 算例图表与工程问题

- 每个主算例先说明对应 `claimId`、系统与工况、具体工程问题、本文方法改变的物理状态或工程决策、代表性比较方法、可直接观察的结果及其工程作用，再确定图表顺序。
- 图组应使读者仅凭图表及图注就能辨认工程问题、本文方法的作用、相同条件下的方法差异和最终工程效果。一张图可以承担多个作用，图表数量由研究内容决定。
- 主文图优先使用节点电压、支路潮流、电流、功率、能量、备用、成本、风险、越限、设备动作和工程决策等领域通用量。每项指标说明定义、单位、维度、优劣方向和对应结论。
- 在相同数据、输入信息、约束、运行方式和指标定义下比较本文方法与代表性方法。主文坐标轴应直接显示工程差异，避免用自定义综合评分、证据完整度、准备程度、检查通过数量或无物理含义的排名替代实际结果。
- 外部对比方法来自电力系统领域期刊，并与当前工程对象、模型和输入条件直接相关，核对原文后登记来源。
- 物理复现用于验证论文主张涉及的模型精度、可信参照一致性或新输出的物理合理性。灵敏度、约束作用、方法组成、运行时间、规模和边界分析按论文问题、参数选择或审稿要求安排。
- 测试系统、源荷时序、概率分布、场景和样本说明可先于结果图出现。结果图按工程关系组织，图表元信息中的 `evidenceRole` 不规定图表顺序，也不要求各类角色分别生成一张图。
- 图表类型应服务可见结果：时序、轨迹和空间剖面采用折线图；网络状态采用网络图或网络热图；分布采用 ECDF、箱线图、小提琴图或可比较的直方图；方法差异采用叠加曲线、配对散点、分组柱图或表格。精确标量通常写入表格或图注。

## 文献中的图型与参数依据

- 编写正式绘图代码前，默认使用 `$powerlit-power-systems-paper-writing` 检查目标期刊及相近工程问题的论文，核对其物理量、比较方法、图型、图表顺序及排版方式。可结合项目参考文献和联网检索；本地 PowerLit 无法访问时，记录实际情况并使用已有文献或联网获得的原文。
- 在图表计划、图注材料、manifest 或证据索引中记录已检查的论文、图型、指标、比较条件和采用的组织方式。文献用于判断图表如何表达工程问题，保留本文自己的数据、结论和图注措辞。
- 参数、灵敏度和参数扫描图先核对同类高水平论文常用的参数名称、范围、步长、归一化方法、默认值及横轴组织。本文采用不同设置时，在图表计划、manifest、图注或证据索引中说明技术原因。
- 参数分析应回答明确问题。选定最方便计算的参数并不构成相应分析的依据。

## 白色背景与图窗

- 全部 MATLAB 图窗和导出文件均采用白色背景，坐标区和图例采用白底，坐标轴及文字使用清晰的黑色；正式图和诊断图均遵守此要求。
- 新图使用 `ProjectName_utils.plotting.create_figure(targetLayout)`；已有图使用 `ProjectName_utils.plotting.apply_white_background(fig)`。支持 `Theme` 属性的 MATLAB 版本显式使用浅色绘图主题，旧版本使用对象颜色设置，保持 MATLAB R2020a 兼容。
- `exportgraphics` 显式指定 `BackgroundColor="white"`；FIG 和 `print` 导出保持相同背景。白底设置失败时应明确报错。
- 使用显式图窗和坐标区句柄。新图默认可见，供作者调整；批处理可显式设置 `Visible="off"`。所有 `.fig` 文件中保存的图窗 `Visible` 属性必须为 `'on'`，每次调用 `savefig` 前显式设置。`save_figure` 保存后恢复源图窗的可见状态，文件中的属性保持 `'on'`。
- 导出默认保留作者调整后的尺寸、长宽比、坐标区、图例和留白，并记录实际尺寸。只有显式设置 `ApplyProfileSize=true` 时才重置图形尺寸。

## 字体、尺寸与全局视觉编码

- 默认配置为 `ProjectName_utils.plotting.figure_profile("ieee")`。目标期刊的明确要求优先于默认配置。
- 默认 `single-column` 宽度为 `8.89 cm`，文字为 `10 pt`。复杂小图可显式设置 `FontSizePt=8` 并写入 manifest。作者可按实际排版选择 `half-column` 或 `double-column`，再调整长宽比及留白。
- 检查配置中的候选字体并记录实际字体，优先使用 Times New Roman、Helvetica、Arial 或 Cambria 等 IEEE 兼容字体。坐标轴线宽、曲线线宽、标记尺寸和分辨率采用当前 profile 中的定义。
- 图形质量的优先顺序为：数据真实性、结果来源、黑白可辨识、字号可读性、目标版面尺寸、美观。
- 配色、线型和标记的选择推荐参考 [EasyPlot](https://github.com/Rimagination/easyplot) 的色带目录与图形可读性建议。根据变量类型、方法数量和图形密度选择方案，使用准确的色带 ID 或明确的 HEX/RGB 值；保持本项目的 MATLAB 绘图和正式导出方式。
- 每个项目在首次正式出图前，将选定方案记录到 `01_IDEA/figure_plan.md` 的“项目配色、线型与标记”一节。记录参考来源及版本或查阅日期、色带 ID、组别顺序，以及每个方法或类别的图例名称、HEX/RGB、线型、标记、标记间隔和适用图件。连续色带补充数值范围、归一化方式和必要的中心值。
- 文档记录与 `methodStyle` 及实际绘图调用保持一致。方案调整时同步文档、代码和受影响的图件，同一对象在不同算例和图件中沿用同一编码；按最终版面尺寸检查图例、曲线重叠及黑白辨识效果。
- 项目全局视觉编码由 `ProjectName_utils.plotting.methodStyle` 维护。同一方法或类别的颜色、线型、标记、灰度及填充图案保持一致，曲线同时使用颜色、线型与标记区分。密集曲线使用 `plot_method_line` 或 `MarkerIndices` 设置稀疏标记。
- 柱状图同时使用灰度、边线和填充图案信息，以便黑白出版辨认。刻度方向遵守当前 profile 或期刊要求。
- 折线图和柱状图使用 `ProjectName_utils.plotting.place_legend(ax)`，默认图内自动位置或 `best`。图例遮挡关键曲线、柱形、峰值或不确定性区间时手动调整。
- 中文正文、主结果比较图、图注、绘图数据及 manifest 将完整方法标注为 `本文方法`，英文稿使用 `Proposed method`。外部方法使用 `AuthorYear` 等来源标签，并登记对应文献。
- 本文方法组成或约束作用对比图中，完整方法标注为 `本文原始方法`，变体使用含义明确的名称，例如 `去掉网络约束`，并说明改变的内容及工程影响。外部论文方法按来源比较。
- 正式图分别导出独立子图，例如 `Fig05a`、`Fig05b` 和 `Fig05c`，在稿件中组合；不将 `subplot` 或 `tiledlayout` 组合图作为最终正式图。

## 数据与比较

- 图表使用已登记的计算结果，保持原始数据含义。筛选、变换、对数轴零值替代和异常点剔除须在绘图数据、manifest 和检查报告中说明。
- 保留曲线中的实际峰值、越限、异常和方法差异。禁止为了视觉效果平滑曲线、删除数据、修改坐标范围或重标数值。
- 结果比较图同时展示参照方法和比较方法；误差图省略参照方法与自身比较的误差。跨阶误差图使用对数坐标时明确处理零值和负值。
- 分布距离结论依赖节点或空间差异时，按节点或对应位置展示。概率密度比较使用参照样本直方图作为背景，叠加各方法 PDF，并导出分箱和 PDF 采样点。
- 每张主要结果图的解释应说明工况、可见变化、定量差异、物理或运行原因、解决的工程问题及工程作用。适用条件与结论保持一致。

## 正式图元信息

导出前在 `01_IDEA/figure_plan.md` 登记算例故事及图表。必需信息缺失时，先补齐具体信息；未满足正式图要求的输出标明为诊断图。

| 信息 | 必需内容 |
| --- | --- |
| 读者与工程结果 | `readerQuestion`、`engineeringObject`、`visibleResult`、`comparedMethods`、`storyContribution` |
| 量与数据 | `metric`、物理量、单位、维度、`dataFiles`、`dataDescription`、预处理说明 |
| 表达与版面 | `visualEncoding`、`targetLayout`、实际尺寸及字体 |
| 科学问题与结果对应关系 | `sciQuestion`、`claimId`、证据编号、`figurePlanId` |
| 交接合同 | `contractVersion`、`templateFigureContractVersion`、`evidenceRole`、`physicsReproduction` |
| 计算条件 | 入口文件、命令、关键参数、求解器、数据版本、Git 状态、环境、随机种子或 `not_applicable` |

- 交接字段遵循 `.cursor/contracts/project-template-handoff.schema.yaml`。基础合同和模板图表扩展的版本分别记录，保持与实际导出一致。
- `physicsReproduction` 在可信参照或模型精度比较适用时填写，否则为 `not_applicable`。
- `evidenceRole` 采用合同允许的 `scenario-setup`、`physical-reproduction`、`sota-comparison` 或 `sensitivity-ablation`。该字段记录图表用途，读者看到的内容由工程量及比较结果决定。
- `save_figure` 检查元信息与导出文件完整性，不通过增加图表或自定义指标补齐某类用途。

## 导出文件与结果登记

- 正式算例图保存在 `result/<case_name>/figures/`，通过 `ProjectName_utils.plotting.save_figure` 导出 FIG、PNG、SVG、适用的绘图数据 CSV、`figure_manifest.jsonl` 和 `figure_check_report.md`。期刊需要 PDF、EPS 或 TIFF 时，从同一图窗和导出函数生成。
- 正式论文图由 MATLAB 统一导出。截图、复制粘贴及其他绘图软件仅用于临时讨论。
- 图表成为论文依据前，在 `01_IDEA/evidence_map.md` 登记图表与 `claimId`、证据编号及结果文件的关系。
- 算例在数值结果及正式图导出结束后写入 `result/<case_name>/run_manifest.json`，确保包含图表与相关证据路径。
- 坐标轴、图注和绘图数据中的量、单位、比较条件及名称保持一致；合同字段与结论、运行记录和图表 manifest 保持一致。
- 稿件使用的图片副本保存在 `02_PAPER/latex/figures/`，相应证据记录同时注明正式导出来源和稿件路径；结果图更新时同步更新稿件副本。
