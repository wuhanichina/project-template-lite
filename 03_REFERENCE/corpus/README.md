# 项目语料库

每篇稿件使用 `<paper>/写作语料.md`，其中 `<paper>` 与 `02_PAPER/` 下的稿件目录同名。优先选读目标期刊中研究对象、方法和文体相近的论文。生成时机和维护要求见[文献整理规则](../AGENTS.md#项目语料库)。题录、原文及术语定义分别引用[文献目录](../Powerlit相关论文本地地址.md)和[专业术语表](../专业术语表.md)中的对应记录。

## 写作语料的内容

文件开头注明当前稿件、研究问题、目标期刊、文体和实际查阅的文献编号。按以下提纲记录原文中观察到的做法。

| 部分 | 从原文中提炼的内容 |
| --- | --- |
| 专业术语与典型句式 | 术语与电气量、运行工况、计算动作或评价指标的搭配，以及句式用于定义、假设、近似、比较或结果解释的场合。 |
| 技术背景与论证顺序 | 作者如何从运行或规划任务提出研究问题，如何依据模型假设、工程条件或文献比较确定所用方法。 |
| 引言 | 各段承担的功能、最接近研究的讨论位置，以及引出研究缺口的事实和回应缺口的贡献。 |
| 方法 | 建模对象、假设和变量的引入顺序，核心公式解决的计算问题，以及公式的电气含义、成立条件和后续用途。 |
| 算例分析 | 各算例检验的判断、参照方法、比较工况及指标，以及作者如何解释图表中的定量差异和工程含义。 |
| 结论 | 作者如何回答开篇问题，保留哪些定量结果，如何说明适用工况和待研究问题。 |
| 小结与衔接 | 作者在段末、节末或独立小结中归纳的内容，以及各节如何承接同一技术问题。 |

每条记录可用 **文献编号与原文位置｜原文短例或结构概括｜用途与适用语境**。位置可用节、页、公式、图表或可定位的段落。原文短例保留原语言，译文和由多篇论文归纳的写法分别标明。归纳共同写法时列出文献编号、采用篇数和实际查阅篇数。撰写本项目稿件时，用本文的模型、推导、数据和结果支撑论述。
