# 03_REFERENCE

本目录维护本文参考文献、专业术语和项目禁用词表，支撑当前工程缺口、方法机理及结果解释。

| 文件 | 内容 |
| --- | --- |
| `Powerlit相关论文本地地址.md` | 完整书目信息、DOI、本文用途及已核实的本地 PDF、JSON 地址 |
| `专业术语表.md` | 已核实术语、待核实候选、中英文对应表达、来源及建模语义要求 |
| `项目禁用词表.md` | 默认禁用词、翻译腔、需核对的数学术语及具体改写方式 |
| `papers/论文发表年份-作者-方法简称.pdf` | 项目需要对标的论文原文，直接保存在 `papers/` 中 |
| 按需保存的阅读笔记和 BibTeX 文件 | 关键文献的工程问题、方法假设、主要结果及引用信息 |

## 文献检索与收录

具体项目立项时，先明确研究对象、当前工程缺口和检索词，默认联网检索相关论文，并检索可访问的本地 PowerLit。阅读原文中对现实需求、工程后果、现有方法及机理原因的论述，核对同类问题的中英文表达。通用模板尚未指定课题，文献目录保留填写格式，数量从零记录。

每个具体项目至少收录 40 篇经核查、与本文直接相关的高水平非中文参考文献。检索覆盖 IEEE TPWRS、TSG、TPWRD、TSTE、TEC、TIA、TII，以及 Applied Energy、Energy、Renewable Energy、Nature、Nature Energy、Nature Communications 等期刊中的电力系统研究，兼顾近期研究、必要经典工作和最接近本文的方法。每篇应说明它支持本文哪个论点或哪项比较。按 DOI 和题名合并重复记录，数量按独立文献统计；中文文献可用于核对中文术语，单独记录。

项目方法对比采用相关高水平期刊中的电力系统研究。期刊来源、论文研究内容及其工程对象、模型、输入条件和评价指标的可比性一并核查，在文献目录中记录筛选依据和具体用途。期刊范围及示例统一见本目录 `AGENTS.md`。

书目信息以出版商页面、DOI 登记信息或正式论文为依据。记录全部作者、年份、期刊、卷号、期号、页码或文章编号。在线优先出版论文注明当前出版状态，卷期页码在正式出版后更新。

检索完成后更新 `Powerlit相关论文本地地址.md`，分别核实 PDF 和全文 JSON 的实际路径；未找到的文件填写实际检索结果。路径来自当前机器的文件检查，不得根据题名或旧机器目录拼接。文献编号与研究笔记、术语表及稿件引用键保持对应。当前论文使用的 BibTeX 条目集中维护在 `02_PAPER/latex/references.bib`。

## 对标论文原文

选定需要对标的论文后，获取完整原文 PDF，统一直接保存到 `03_REFERENCE/papers/`，该目录不再下设子文件夹。文件名采用 `论文发表年份-作者-方法简称.pdf`：年份使用已核实的发表年份，作者采用第一作者姓氏的原文拼写，方法简称使用原文已有简称或项目确认的简短方法名。优先使用出版商、作者或机构资料库提供的版本；本地 PowerLit 已有原文时复制到此目录。

检查 PDF 可打开，并核对题名、作者、DOI 和论文完整性。在 `Powerlit相关论文本地地址.md` 中记录项目内相对路径、来源、版本、获取日期及具体对标用途，保留原有 PowerLit 地址。方法实现和结果对比以实际取得的原文及其假设、参数和算例条件为依据。

## 术语维护

写入项目文档前读取 `项目禁用词表.md`，逐句检查用词和语义。禁用表达与改写方式集中维护，核实后的专业术语及其来源记录在 `专业术语表.md`。

研究对象、工程问题、物理量、方法名称和其他专业术语在首次使用前核对来源。中文和英文对应表达分别记录原文依据，必要时补充标准、权威教材或专业机构资料。说明含义、适用条件和近义词之间的技术区别。术语、符号或模型定义改变时，同步更新术语表、`01_IDEA/symbols.md` 和相关正文。

专业术语查证后才能写入项目正文，优先参考同类期刊原文，未核实表达留在候选区。建模语句按照定义、事实、假设、近似、能力或观察结果选择 `can`、`is` 等结构，并保留其成立条件。表中记录相应检查要求。

Git 默认跟踪筛选后的目录、术语表、阅读笔记和引用信息。大型文献库保留在本地 PowerLit。
