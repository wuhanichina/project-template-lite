# AGENTS.md

本目录维护参考文献、本地 PowerLit 地址、中英文专业术语及项目禁用词表。根目录的表达和验证规则同时适用。

## 检索与文献数量

- 立项时先明确实际运行或规划任务、工程对象、当前研究缺口和中英文检索词，默认联网检索，并检索可访问的本地 PowerLit。
- PowerLit 使用已配置的索引或检索技能；本地资料不可访问时，继续读取出版商页面、DOI 登记信息和可获得的原文。记录实际检索来源和文件状态。
- 阅读同类论文对现实需求、紧迫性、输入假设、方法能力、具体不足、机理原因和工程后果的论述。标题和关键词仅用于筛选，论文用途依据原文确认。
- 每个具体项目至少收录 40 篇独立、经核查、直接相关的高水平非中文文献。优先检索目标期刊，再扩展到适合该问题的 IEEE TPWRS、TSG、TPWRD、TSTE、TEC 及其他高水平期刊，兼顾近期研究、必要经典工作和最接近本文的方法。
- 按 DOI 和规范题名合并重复记录。每篇文献连接本文的具体论点、模型依据或方法比较。中文文献可用于核查中文术语，单独记录。
- 通用模板尚未指定课题时保留空目录格式，已核查文献数量为零。不得编造题名、作者、出版信息、DOI、路径、结果或引用用途。

## 书目信息与本地地址

- 检索完成后更新 Markdown 文献目录 `Powerlit相关论文本地地址.md`，逐篇记录文献编号、引用键、完整题名、全部作者、语言、期刊、年份、卷号、期号、页码或文章编号、DOI、出版状态和核查来源。
- 元数据依据出版商页面、DOI 登记信息或正式原文核对；在线优先出版状态如实记录，卷期页码发布后更新。
- 分别检查本机 PowerLit PDF 和全文 JSON 是否存在，记录确实检查过的完整路径。未找到的文件记录实际检索结果，避免依据题名或其他机器目录拼接。
- 每篇说明研究问题、适用条件、主要成果、现有不足、本文用途及对应正文位置。编号与研究笔记、术语表和稿件引用键保持对应。
- 当前论文的 BibTeX 条目维护在 `02_PAPER/latex/references.bib`，保留全部作者及准确出版信息。Git 跟踪筛选后的目录、术语表和阅读材料，大型文献库留在本地 PowerLit。

## 对标论文原文

- 项目选定用于方法对比、模型比较或关键结果对照的论文后，必须获取完整原文 PDF，统一直接保存到 `03_REFERENCE/papers/`，该目录不再下设子文件夹。从出版商、作者或机构资料库下载；已有本地 PowerLit PDF 时，复制到此目录，保留原始文件。
- 文件名采用 `论文发表年份-作者-方法简称.pdf`。年份使用已核实的发表年份，作者采用第一作者姓氏的原文拼写，方法简称使用原文已有简称或项目确认的简短方法名，并在文献目录中说明。正文保留原始题名。获取后检查 PDF 可打开，并核对题名、作者、DOI 和论文完整性。
- 在 `Powerlit相关论文本地地址.md` 的对应条目中记录对标用途、项目内 PDF 相对路径、获取来源、版本及日期，同时保留已核实的 PowerLit PDF 和 JSON 地址。
- 方法实现和结果对比依据实际取得的原文，核对其模型假设、输入信息、参数和算例条件。尚未取得原文时，在文献条目记录实际获取状态，继续获取原文。

## 专业术语

- 写作前读取 `项目禁用词表.md`，按其适用语境检查禁用词和翻译腔。新增条目写明具体改写方式，核实后的专业表达同步维护在 `专业术语表.md`。
- 立项时先核查研究对象和工程问题的常用中英文表达，其他专业术语必须查证后才能使用。优先阅读对象和模型相近的目标期刊原文，未核实的候选仅记录在术语表候选区。
- 在 `专业术语表.md` 维护中文、英文及缩写、定义、对应工程对象、适用条件、近义词的技术区别、两种语言的来源与位置、文献或标准编号、本文使用位置及核查日期。
- 使用相关原始论文、标准、权威教材或专业机构资料核查术语。不同语言的术语分别注明依据，不凭直译推定等价。
- 定义、符号或模型变化时，同步术语表、`01_IDEA/symbols.md`、研究笔记及受影响的稿件。
- 核对名称的同时核对建模表述：根据定义、假设、近似、能力或算例结果选择 `can`、`is` 等结构，查证条件和谓语的实际含义，避免频繁使用没有具体指代的“物理”。
